# Up2Date

A modern macOS app to keep your applications up to date.

## 🚀 Vision

Up2Date aims to be the single place to manage updates for all your apps on macOS:

- App Store apps
- Apps using Sparkle
- Homebrew packages

Clean, fast, and fully native — built with SwiftUI and modern Swift.

---

## ✨ Features (Planned)

- 🔍 Detect installed applications automatically
- 📦 Check for updates across multiple sources
- ⚡ Unified update experience
- 🔄 Optional automatic updates
- 🧠 Smart prioritization of updates

---

## 🏗 Architecture

Up2Date follows a modular architecture:

- **Core** – domain models & logic
- **Data** – update sources (App Store, Sparkle, Brew)
- **Infrastructure** – system integrations
- **Application** – state & orchestration
- **UI** – SwiftUI interface

See [`docs/`](docs/) for detailed documentation.
