# Up2Date – Konzept

## Ziel
Up2Date ist eine moderne macOS App zur zentralen Verwaltung und Aktualisierung installierter Anwendungen.

## Unterstützte Quellen
- App Store Apps
- Sparkle Updater Apps
- Homebrew (brew upgrade)

## Kernfunktionen
- Automatische Erkennung installierter Apps
- Update-Erkennung pro Quelle
- Einheitliche Update-UI
- Automatisierte Updates (optional)
- Hintergrund-Checks

## UX Prinzipien
- Minimalistisch (Apple-like)
- Transparenz über Updates
- Kein unnötiger Input notwendig

## Nicht-Ziele
- Paketmanager ersetzen
- Eigene Update-Server betreiben
